# Links decorative assets

`oak.webp` is an AI-generated oak silhouette with transparent background, created
2026-10-23 for this game and resized/encoded as WebP (738 × 1024, quality 82).
It is decorative scenery, not photography or surveyed vegetation at any course.
The renderer places it at the game's existing simulated tree positions; it does
not change trees, lies or hazards in course packs. No third-party photo is used.
